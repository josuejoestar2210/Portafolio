## 📂 Proyectos Destacados

### 🏨 Sistema de Gestión Hotelera (Hotel Victoria)

Durante mi experiencia en el Hotel Victoria (Agosto 2025 – Marzo 2026), diseñé y desarrollé un sistema integral que incluye:

* **Módulos:** Reservas, clientes, habitaciones, ventas, inventario y control de gastos.
* **Seguridad:** Autenticación y control de acceso basado en roles con ASP.NET Core Identity.
* **Optimización:** Consultas avanzadas con EF Core (Lazy/Eager Loading y paginación).
* **Reportes:** Generación de documentos en PDF (QuestPDF) y exportación a Excel (ClosedXML).
* **Automatización:** Lógica asincrónica para estados de habitaciones y reservas.

### 🎬 AnimeApp — Plataforma Web Full Stack

Proyecto personal construido con **Angular** y **Supabase**, desplegado en producción:

* **Funcionalidades:** Registro/login, búsqueda de anime, favoritos, lista de seguimiento (watchlist) y sistema de reseñas con calificación por estrellas.
* **Backend como servicio:** Supabase (PostgreSQL) con Row Level Security (RLS) para aislar datos por usuario.
* **Consumo de API externa:** integración con una API REST multi-proveedor, manejando datos inconsistentes entre fuentes.
* **Reproductor integrado:** selección de servidor de video e idioma (sub/doblado).
* **Despliegue real:** frontend en Netlify, API en Render (Node.js), con variables de entorno por ambiente.
